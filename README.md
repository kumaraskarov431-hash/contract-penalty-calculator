# Калькулятор пени по договорам

Автономное веб-приложение для Отдела сопровождения договоров Дирекции управления проектами АО «Казахтелеком».

Откройте сайт или `dist/index.html` в современном браузере. Установка и сервер для автономного использования не нужны. Все библиотеки находятся в `dist/vendor`; запросы из расчётной логики запрещены политикой Content Security Policy. Договорные данные не отправляются на сервер и не сохраняются в localStorage.

## GitHub Pages

Адрес сайта: https://kumaraskarov431-hash.github.io/contract-penalty-calculator/

Исходники находятся в ветке `main`. GitHub Pages публикует корень ветки `gh-pages`, содержащий только файлы из `dist`. Присланный Excel-образец, учебные выгрузки, локальные журналы и проверочные материалы в репозиторий не включаются.

Для обновления сайта сохраните изменения коммитом, отправьте `main` в GitHub и выполните `powershell -File scripts/publish-pages.ps1`. Скрипт отправит актуальные файлы из закоммиченного `dist` в ветку `gh-pages`. GitHub Pages обновит сайт после завершения публикации.

## Локальный сайт

Для запуска по локальному веб-адресу выполните `npm start` или `node scripts/serve.cjs`. По умолчанию сайт доступен по адресу `http://127.0.0.1:8080/`. Если порт занят, выбирается следующий свободный порт; точный адрес выводится при запуске. Сервер доступен только на этом компьютере и отдаёт только файлы из `dist`. Все расчёты и создание Excel выполняются в браузере.

## Расчёт

Начало просрочки: следующий день после установленного срока. Конечная дата включается согласно переключателю. Даты преобразуются в целые номера UTC-дней. Периоды исключений включают обе границы, пересечения объединяются. Интервалы начисления не должны пересекаться. Пропуски учитываемых дней помечают результат как неполный и отражаются в выгрузках.

Используется Decimal.js с точностью 100 значащих цифр. Ввод ограничен 18 цифрами целой части, 2 десятичными знаками для сумм и 8 для процентов, не более 500 интервалов и исключений; этого достаточно для точных произведений и сумм без промежуточного округления. Ограничение применяется к общей точной сумме, затем итог округляется до двух знаков по ROUND_HALF_UP. Предел, заданный процентом, тоже не округляется до применения. Итог в тиынах может отличаться от точного предела меньше чем на половину тиына из-за финального округления.

Печать через браузер включает все исходные данные, интервалы, исключения, формулы и округление. ExcelJS создаёт настоящий `.xlsx` в форме присланного образца: один лист `расчет пени`, шапка договора, семь граф, строка «Всего», база ограничения и итог. Для каждого интервала добавляется строка основной таблицы. Исключения, исходные данные, точные формулы и округление приводятся ниже на том же листе. Пункт договора о пене можно заполнить в отдельном необязательном поле; условия из образца не подставляются.

Суммы, ставки и даты экспортируются числовыми значениями и датами Excel с соответствующими форматами. Если значение превышает точность Excel (15 значащих цифр), оно сохраняется точным десятичным текстом. Формулы строк, суммы и процентного ограничения получают рассчитанные значения. Итоговая пеня зафиксирована по точной десятичной арифметике приложения, чтобы перерасчёт Excel в двоичной арифметике не изменил итог. Для новых условий нужно заново выгрузить расчёт из приложения. Тексты не интерпретируются как формулы Excel. Учебный пример помечен как вымышленный в интерфейсе и всех формах отчёта.

## Разработка

Зависимости закреплены в `package.json` и `pnpm-lock.yaml`. После установки зависимостей выполните `node scripts/prepare-vendor.cjs` для обновления локальных браузерных библиотек. Их лицензии находятся в `dist/vendor`.

Проверка арифметики и отчётов: `node --test tests/core.test.cjs`.
Проверка браузера: `node tests/ui.cjs` (требуется Playwright и установленный Chromium; путь к Playwright можно передать через `PLAYWRIGHT_MODULE`). Скриншоты и проверочный PDF создаются в `qa/`.
